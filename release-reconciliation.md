# Проверочный список релиза TG TOP

Этот список — единый критерий приёмки. Новые изменения не публикуются, пока затронутый пункт не проверен в локальной сборке и в production.

## Листинг и карточка сообщества

- [ ] В настройках листинга нет блоков «Анонимное размещение» и «Платный вход недоступен».
- [ ] Управление видимостью владельца находится только в профиле через переключатель публичного аккаунта.
- [ ] Платный вход Stars показывается только для подходящего приватного канала.
- [ ] Для приватного сообщества владелец может создать обычную закрытую ссылку; при ошибке выводится понятная причина о правах бота или типе сообщества.
- [ ] Переход в сообщество открывает Telegram без закрытия TG TOP и возвращает пользователя на прежний экран Mini App.
- [ ] Клик по публичной карточке владельца открывает его Telegram-аккаунт через `t.me/@username`; анонимная карточка не является ссылкой.

## Рейтинг и цена позиции

- [ ] В деталях сообщества нет служебных плашек «В каталоге с …» и «Выделенная позиция».
- [ ] В блоке рынка используется понятная «Цена лота» с текущей и минимальной ценой в GRAM.
- [ ] Отображается таймер непрерывного удержания конкретной рейтинговой ячейки с посекундным обновлением.
- [ ] При перемещении группы в другую ячейку её таймер сбрасывается; таймер карточек, не меняющих ячейку, не сбрасывается.

## Профиль и личный кабинет

- [ ] Профиль показывает реальные балансы и историю операций, а после подтверждённой награды обновляется автоматически.
- [ ] В истории нет двойных знаков минуса и технических кодов операций.
- [ ] Кошелёк подключается из профильного блока, а верхняя навигация остаётся компактной.
- [ ] Публичный переключатель объясняет, что только публичный аккаунт появляется в лидерборде.
- [ ] @TGTOP_robot отправляет краткое сообщение о каждом подтверждённом начислении GRAM.

## Мои сообщества и мобильная компоновка

- [ ] Раздел «Мои» поддерживает добавление, выбор, размещение, снятие с каталога и удаление без перекрытия последних карточек нижней панелью.
- [ ] У неразмещённых сообществ нет плашки «Не в листинге»; остаются только значимые статусы.
- [ ] Основные кнопки листинга и подтверждений остаются выше нативной нижней панели Telegram.
