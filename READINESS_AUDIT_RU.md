# TG TOP — технический readiness-аудит

Дата аудита: 2 сентября 2026.

Проект **можно начинать тестировать в закрытом режиме** на реальных Telegram-аккаунтах и ограниченном числе групп. ## Можно ли начинать тестирование

Да — **закрытое функциональное тестирование уже можно начинать**. Рекомендуемый порядок: новый Telegram-аккаунт, открытие Mini App, добавление тестового канала/чата через `@TGTOP_robot`, проверка появления в My Groups, открытие карточки, настройка категории и географии, listing на тестовый слот и проверка записи бонуса/операции.

Тестирование следует проводить с небольшим числом площадок и без реальных TON-платежей. Все операции, которые выглядят как bid, должны оставаться внутренними intents до включения on-chain verification; автоматические выплаты не включать.

## Блокеры публичного запуска

| Приоритет | Риск | Почему важно |
|---|---|---|
| P0 | Живая проверка production auth, onboarding и защищённой мутации | Без неё нельзя гарантировать, что новый пользователь действительно сможет пройти весь путь |
| P0 | Проверка HTTPS Mini App URL в BotFather и Main App | Без неё запуск из нужных Telegram-точек может быть неполным |
| P0 | Исправление расчёта listing charge и возврат затронутых 0.9 GRAM | Это финансовая корректность и доверие пользователей |
| P1 | TON transaction verification и safeguards до реальных платежей | Нельзя включать реальные списания/выплаты без подтверждения транзакций и защиты от повторов |
| P1 | Pagination, request controls и дополнительные query safeguards | Нужны до существенного трафика и большого каталога |
| P1 | Реальная проверка mobile owner workflow | Нужна для исключения регрессий именно в Telegram WebView |

## Что не блокирует закрытый тест

Реферальный dashboard, TGStat-grade историческая аналитика, TON Site, NFT deposit bot, staged group sale и полноценная owner cabinet являются следующими этапами. Они важны для масштабного продукта, но не мешают проверить базовую связку каталог → onboarding → ranking → listing при отключённых реальных платежах.

## Безопасные исправления, уже сделанные в рамках аудита

Устаревший source-level тест после выноса `NftShowcase` из `Home.tsx` был исправлен: теперь интеграционный тест проверяет импорт и отдельный компонент. После исправления полный gate восстановлен: 295 тестов прошли, 3 пропущены; TypeScript и production build также проходят.

## Следующий рекомендуемый шаг

Сначала провести один ручной production smoke с новым Telegram-аккаунтом и тестовой группой. Если он проходит, начать закрытый набор тестировщиков. До исправления P0-пунктов не покупать трафик, не открывать массовое подключение групп и не включать реальные TON-платежи.
