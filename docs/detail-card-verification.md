# Проверка карточки деталей лота

## Production-проверка

20 августа 2026 года на `https://tgtop.xyz` была открыта карточка реального сообщества `@F_I_N_E_G_O_L_D` после развёртывания обновления. Экран подтверждает, что общий шаблон применяется к реальным данным, а не только к локальной разметке.

| Проверенный элемент | Результат |
| --- | --- |
| Верх карточки | Видны бейдж позиции, статус «В ТОПЕ», живой таймер и крупный центральный аватар с процентом роста. |
| Ряд действий | Отрисованы три компактные карточки: текущая ставка, менеджер и синий переход в группу. |
| Аналитика | Отображается один заголовок «Динамика аудитории», без старого вложенного дубля графика. |
| Метрики | Под графиком показаны две ячейки «Вступления» и «Приглашения». |
| Панель ставки | Отрисована единая нижняя панель с суммой, контролами минус/ввод/плюс и зелёным действием «Сделать ставку». |

Тестирование и production-сборка этой версии завершились успешно до развёртывания.
