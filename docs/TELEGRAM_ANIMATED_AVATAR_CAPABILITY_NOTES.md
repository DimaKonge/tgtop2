# Анимированные аватары Telegram: техническая граница

Проверено 26 августа 2026 года по официальной документации Telegram Bot API: `getChat` возвращает для чата объект `ChatPhoto` с файловыми идентификаторами статического фото. API отдельно поддерживает анимированное фото для **собственного профиля бота**, но этого недостаточно, чтобы бот надёжно выгружал анимированный avatar любого подключённого канала или группы.

Следствие для TG TOP: текущий Mini App уже умеет показывать сохранённый `animatedAvatarUrl` с обычным Telegram-аватаром как fallback. Для автоматической загрузки анимированных аватаров сообществ потребуется отдельный, явно согласованный источник, который законно предоставляет video/avatar media для канала (например, пользовательская Telegram-сессия с минимальными правами). До его подключения новый листинг обязан сохранять и показывать обычный Bot API avatar без имитации анимации.

Источник: [Telegram Bot API — ChatPhoto и profile media](https://core.telegram.org/bots/api).
